# 🎮 Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors** game developed using **HTML, CSS, and JavaScript**. The game allows users to play against the computer with real-time score updates and dynamic game messages.

---

## 📌 Project Overview

This project was developed as the **Final Project** during my **Web Development Internship at Vault of Codes**. The objective was to build an interactive web application by implementing HTML for structure, CSS for styling, and JavaScript for game logic and user interaction.

---

## ✨ Features

- 🎮 Player vs Computer gameplay
- 🤖 Random computer choice generation
- 📊 Real-time score tracking
- 🏆 Automatic winner determination
- 🎨 Interactive user interface
- 🖱️ Hover effects on game choices
- 📱 Responsive and clean design
- ⚡ Instant game result updates

## 🚀 How to Run the Project

1. Clone the repository

```bash
git clone https://github.com/your-username/rock-paper-scissors.git
```

2. Navigate to the project folder

```bash
cd rock-paper-scissors
```

3. Open **index.html** in your browser.

No additional software or installation is required.

---

## 🎯 How to Play

1. Open the game in your browser.
2. Click on either **Rock**, **Paper**, or **Scissors**.
3. The computer automatically selects its move.
4. The winner is decided based on the game rules.
5. Scores are updated after every round.
6. Continue playing as many rounds as you like.

---

## 📖 Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same choices result in a Draw
